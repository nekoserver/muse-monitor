## 不足（Lint では補えないもの）

- 前提 P5（DO のストレージ自体が読めない場合の手段のなさ）は未実測のままである。実測する手段が現時点でなく、債務として前提節と未決事項に残る。
- REQ-SEC-034（ダッシュボードのログイン状態表示）は版8で新設した要求であり、評価時点では未実装である。AC-SEC-011 の判定は実装とデプロイ後の実物確認が済むまで保留される。
- REQ-SEC-032 の期限日の記録は未実施である（値は運用者の管理画面でしか分からない）。台帳には未記録である旨が明記されている。
- 2026-11-16 の NoState 固定について、lastError の文面による原因の確定はできていない。状態破棄で復旧した事実はあるが、破損の確定診断ではない。SPEC の参考記録にはその旨が正しく書かれている。

## 改良への入力

- 低: P5 を実測できる機会（DO のストレージ障害に相当する事象）があれば、前提節の検証状態を更新する。
